# Welcome

This is your personal knowledge base. Content gets posted here directly from ChatGPT and Claude via the GitHub API.

## How it works

1. You're chatting with an AI about something useful
2. You say "post this to the knowledge site"
3. The AI commits a markdown file to this repo via GitHub API
4. AWS Amplify auto-deploys the update
5. It shows up here within seconds

## Categories

Posts are organized by topic category and are also browsable chronologically. Use the nav to filter by category or browse everything in order.
